# actualize.js

Подставляет в фреймы плеера ASG рабочий домен, если основной заблокирован.

```html
<script src="https://focusiptop-blip.github.io/actualize.js" async></script>
```

Домен сменился — поправьте список `DOMAINS` в `actualize.js` (рабочий — первым) и отправьте изменения: GitHub Pages обновится за минуту-две.
